# Rain-Forecasting
Developed monthly rainfall forecasting model for Mumbai to optimize reservoir planning , improve allocating decisions , cut costs, and  ensure reliable supply
## Technology Used
- Python
- Pandas
- Numpy
- Scikit-learn
- Matplotlib
- Seaborn
- Plotly
- Tensorflow
- ## Models Used
- Linear Regression
- Random Forest
- Gradient Boosting
- LSTM
